# 👋 Personal Profile Card

A simple and elegant **personal profile card webpage** built using HTML and CSS. This project showcases a modern UI design with a glassmorphism effect and responsive layout.

---

## 📌 About the Project

This project is a single-page personal introduction card featuring:

* A stylish gradient background
* Glassmorphism card design
* Personal introduction and details
* GitHub profile link with hover animation
* Fully responsive layout for mobile devices

---

## 🚀 Features

* 🎨 **Modern UI Design** – Clean and visually appealing layout
* 💎 **Glassmorphism Effect** – Blurred background with transparency
* 📱 **Responsive Design** – Works on both desktop and mobile screens
* 🔗 **GitHub Integration** – Direct link to profile
* ⚡ **Lightweight** – No frameworks, pure HTML & CSS

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* Flexbox
* Media Queries

## ✏️ Customization

You can easily personalize this project:

* Change the **name and description** inside the HTML
* Update your **µlearn ID**
* Replace the **GitHub profile link**
* Modify colors in the CSS gradient:

  ```css
  background: linear-gradient(135deg, #1e3c72, #2a5298);
  ```
